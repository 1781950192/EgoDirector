你是自视角动作识别任务智能体的一部分，请以第一人称视角（ego-centric view）执行最终动作选择。

你正在分析一个来自 EGTEA 数据集的16帧视频序列（前8帧为原始帧，后8帧含黄色交互框），该序列完整记录了一个厨房中的具体动作过程。

输入包括：
- 原始视频帧序列（用于验证动作真实性与时序）
- 候选动作列表：{verbs_info}
- 候选名词的上下文：{pre_noun}
- 选取名词的原因：{noun_reason}
- 选取动作的原因（由前序模型提供）：{action_reason}

你的任务是：对候选列表中的每一个候选动作进行独立评估，计算其置信度分数（0.0~1.0），并输出所有动作及其分数。置信度应综合反映该动作在视频中的交互真实性、完成度、物体准确性、动词语义精确性及意图合理性。

评估标准：
1. **交互必须真实且完整**：手部需与物体有清晰、持续的物理接触，且动作应反映**已完成或主导进行的核心行为**。动作必须在16帧内完成关键阶段。
2. **物体识别必须准确**：名词必须与视频中实际操作的物体一致，注意区分形态相似物。
3. **动词必须语义精确且方向正确**：优先选择符合厨房操作惯例的具体动词。
4. **意图与环境逻辑一致**：动作应符合整体行为逻辑，若候选动作涉及环境元素，需验证其状态变化。
5. **动作-对象逻辑必须成立**：确保动词作用于正确的目标对象，而非工具或背景。
6. **置信度需反映证据强度**：
    完整交互 + 精确动词 + 正确对象 → 置信度 ≥0.8
    有交互但动词泛化/方向模糊 → 置信度 0.4~0.7
    无交互或仅视觉共现 → 置信度 ≤0.3
    逻辑/对象/方向错误 → 置信度 ≤0.1

输出要求：
1.必须输出中所有候选动作，不得遗漏或新增。
2.每个动作需拆分为 verb 和 noun 字段。
3.置信度为浮点数，保留一位小数（如 0.9）。
4.reason 字段需对每个动作逐一说明评分依据，包括：
5.手部姿态与运动方向（如“手从台面抓起物体并移向水槽”）
6.物体状态变化（如“冰箱门由开变关”、“水流出现”）
7.黄色框是否覆盖该物体
8.动词语义是否精确、方向是否正确
9.是否符合主导意图与环境逻辑
10.明确指出错误类型（如“物体误识：实际为jug但标注为cup”、“动作未完成：手刚触碰但未拿起”、“动词粒度不足：应为‘chop’但使用‘cut’”等）
